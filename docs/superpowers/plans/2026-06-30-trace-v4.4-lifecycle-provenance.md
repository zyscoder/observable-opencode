# Trace v4.4 Lifecycle + Provenance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Trace v4.4 lifecycle and provenance records for LLM turns, exit gates, compaction, subagents, and evidence facts.

**Architecture:** Keep v4.3 compatibility while adding focused semantic records. `CaseTrace` remains the trace writer; session/tool code emits lifecycle facts; the viewer groups the new facts in `trace.html`.

**Tech Stack:** TypeScript, Bun tests, existing opencode observability modules.

## Global Constraints

- Keep `trace.html` as the only HTML entry point.
- Do not add diagnosis/root-cause conclusions to trace generation.
- Do not promote stream deltas into formal records.
- Preserve existing major v4.3 fields unless a test proves an intentional replacement.
