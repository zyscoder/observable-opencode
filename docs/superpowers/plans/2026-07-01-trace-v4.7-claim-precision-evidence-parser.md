# Trace v4.7 Claim Precision And Evidence Parser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve v4.6 claim precision and evidence parsing so trace records are less fragmented, less generic, and less over-attributed.

**Architecture:** Keep the v4.6 schema and add focused v4.7 fields. Upgrade claim splitting, evidence canonicalization, claim-evidence matching, trace health counters, viewer display, and forced compaction behavior.

**Tech Stack:** TypeScript, opencode observability trace writer, static HTML renderer, session prompt/compaction code, `tsgo --noEmit`, `git diff --check`, GitHub Actions release.

## Global Constraints

- Do not add root-cause diagnosis inside opencode.
- Do not restore `viewer.html`.
- Keep large payloads in artifacts.
- Do not re-enable stream delta records.
- `OPENCODE_TRACE_FORCE_COMPACTION=1` must only affect trace-enabled validation behavior.
